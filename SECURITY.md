# Security and privacy reports

Use GitHub private vulnerability reporting for unreleased vulnerabilities or security and privacy issues:

https://github.com/better-day-tech/anesthesia-sheet-support/security/advisories/new

Do not include patient, staff, or facility identifiers, real-case data, identifiable screenshots, encrypted backups, recovery keys, or passphrases. This channel is not available for emergencies, individual case consultation, diagnosis, medication advice, or patient-management advice.

Public bug reports and feature requests belong in GitHub Issues and must use fictional data only. Individual replies and response times are not guaranteed.
