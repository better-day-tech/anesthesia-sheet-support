日本語

AnesthesiaSheetのサポートは、不具合報告、機能要望、基本的な使い方の共有、更新告知を目的としています。個別返信や対応時期は保証していません。

公開サポート窓口

GitHub Issuesは、インターネット上で誰でも閲覧できる公開ページです。投稿前に個人情報や症例情報が含まれていないことを確認してください。

GitHub Issuesを開く

非公開の安全性報告

公開前の脆弱性、セキュリティまたはプライバシー上の問題は、GitHubの非公開報告機能を使用してください。患者・職員・施設を識別できる情報、実症例データ、復旧キーは送信しないでください。この窓口は緊急対応や個別症例相談には使用できません。

非公開で安全性の問題を報告

投稿前の確認

  • アプリのバージョン、iOSのバージョン、端末名を記載する
  • 再現手順と、期待した結果・実際の結果を記載する
  • 患者氏名、患者ID、生年月日、住所、電話番号を含めない
  • 施設名、職員名、症例日時など、組み合わせにより個人を識別できる情報を含めない
  • 再現用の入力とスクリーンショットには架空データだけを使用し、実症例データを使用しない

スクリーンショットの墨消しだけでは、通知、写真、ファイル名、位置情報などが残る場合があります。 投稿前に画像全体を確認してください。

対応範囲

個別症例の相談、緊急対応、診断、投薬や患者管理に関する助言は行いません。AnesthesiaSheetは個人メモと自己振り返りの補助アプリであり、公式記録や臨床判断の代替ではありません。

暗号化バックアップの一般的な操作手順はオフライン復元ページで案内します。復旧キーの照会、再発行、代行復号、個別症例データの受領は行いません。

English

Support is provided through public GitHub Issues for bug reports, feature requests, basic usage discussion, and release notices. Individual replies and response times are not guaranteed.

Use GitHub private vulnerability reporting for unreleased vulnerabilities or security and privacy issues. Do not submit patient, staff, or facility identifiers, real-case data, or recovery keys. This channel is not available for emergencies or individual case consultation.

Before posting

  • Include the app version, iOS version, device model, and reproducible steps.
  • Do not include patient, staff, or facility identifiers.
  • Use only fictional data in reproduction steps and screenshots. Do not use real-case data.
  • Remember that GitHub Issues are publicly visible on the internet.

Individual case consultation, emergency support, diagnosis, medication advice, and patient-management advice are not provided. AnesthesiaSheet does not replace official records or clinical judgment.

General encrypted-backup instructions are available on the offline recovery page. Recovery-key lookup, reissue, decryption on a user's behalf, and receipt of individual case data are not provided.
