日本語

AnesthesiaSheetは、麻酔症例の個人メモ、手入力による術中記録、症例振り返りを補助するアプリです。

保存される情報

症例メモ、バイタル、投与ログ、IN/OUT、設定値、ユーザーが登録した指導医リストなどは、ユーザーの端末内に保存されます。

外部送信と共有

アプリは外部アカウントを作成せず、症例データを開発者サーバーへ送信しません。ユーザーがiOSの共有機能を使ってデータを書き出した場合、その共有先には各サービスのプライバシーポリシーが適用されます。端末バックアップに含まれるデータは、ユーザーのiOSおよびiCloudの設定に従って管理されます。

このサポートサイト

このサイトは独自のCookie、アクセス解析、広告を使用していません。サイトはGitHub Pagesで配信されるため、アクセス時の情報はGitHubのプライバシーステートメントに従って処理される場合があります。

患者識別情報

患者氏名、患者ID、生年月日、住所、電話番号など、患者を識別できる情報は入力しない運用を想定しています。症例日時、施設名、職員名なども、組み合わせにより個人を識別できる場合があります。

データ削除

アプリ内の設定から症例データを全削除できます。この操作では保存済み症例と現在の作業症例を削除し、新しい空の仮症例を作成します。指導医リストなどのアプリ設定は、別途変更しない限り保持されます。端末バックアップに既に保存されたデータの保持期間は、Appleのバックアップ設定に従います。

サポート投稿

GitHub Issuesへユーザーが投稿した内容は公開され、GitHubが管理します。患者、職員、施設を識別できる情報や実症例のスクリーンショットを投稿しないでください。

医療上の位置づけ

このアプリは公式麻酔記録、医療機器、診断ツール、投薬指示システムではありません。最終判断には公式記録、添付文書、施設プロトコル、医療者の臨床判断を優先してください。

English

AnesthesiaSheet is a personal support app for anesthesia case notes, manually entered intraoperative records, and post-case review.

Data stored

Case notes, vital signs, medication logs, IN/OUT records, settings, and user-entered supervisor lists are stored on the user's device.

Transmission and sharing

The app does not create an external account and does not transmit case data to a developer-operated server. When a user exports data through the iOS share sheet, the selected service's privacy policy applies. Data included in a device backup is managed according to the user's iOS and iCloud settings.

This support site

This site does not use first-party cookies, analytics, or advertising. It is delivered through GitHub Pages, which may process access information under the GitHub Privacy Statement.

Identifiers

Users should not enter patient-identifiable information. Dates, facility names, and staff names may also identify a person when combined with other details.

Deletion

Users can delete all case data from Settings. This removes saved cases and the current working case, then creates a new empty draft. App settings are retained unless changed separately. Data already included in a device backup remains subject to Apple's backup settings.

Public support posts

Content submitted to GitHub Issues is public and managed by GitHub. Do not post patient, staff, or facility identifiers or real-case screenshots.

Medical boundary

This app is not an official anesthesia record, medical device, diagnostic tool, or medication order system. Final clinical decisions must follow official records, package labeling, local protocols, and clinician judgment.
