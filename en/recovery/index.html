Recovery Kit v1

Recover an encrypted backup offline

This page is for backups created with Anesthesia Memo Pro. Save the recovery tool to a Mac, open it as a local file, and recover TXT or JSON. Do not enter a case file or recovery key into this website.

日本語 English

Recovery steps

  1. Download Recovery Tool v1.
  2. If needed, verify the SHA-256 checksum below and disconnect from the network.
  3. Open the downloaded HTML file from Finder and confirm that the address begins with file://.
  4. Select the .anesbackup file and enter the recovery key or passphrase.
  5. Save the result as readable TXT or complete JSON.

Downloads

Recovery Tool v1 Single HTML file, no external dependencies SHA-256 Checksum for integrity verification

Decryption is disabled while the recovery tool is served over the web. It can decrypt only after it has been downloaded and opened locally. This tool does not re-import data into the app.

Security and limitations

  • The archive uses AES-256-GCM and PBKDF2-HMAC-SHA256. The format and recovery code are public so that the process can be independently reviewed.
  • Store the recovery key separately from the backup file. The developer cannot reissue a lost key.
  • The recovery tool uses no external network connection, analytics, advertising, or third-party library. Its Content Security Policy also blocks network communication.
  • Keep required official records in an approved system in case of device failure, damaged files, or a lost key.
Recovered files are not encrypted

Review the contents and your institution's rules before moving recovered TXT or JSON into a shared folder or cloud service.
